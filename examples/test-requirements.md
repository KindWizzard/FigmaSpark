# Тестовое ТЗ для FigmaSpark

Эти требования относятся только к отдельному проверочному файлу. Они намеренно содержат расхождения, чтобы проверить отчёт плагина.

1. Фрейм имеет ширину 640 px и высоту 360 px.
2. Заголовок экрана: «Players».
3. Размер шрифта заголовка: 28 px. В проверочном макете задано 24 px.
4. На экране есть текстовая кнопка «Reset filters». В проверочном макете она отсутствует.
5. Кнопка должна работать в приложении. Статический макет не доказывает это поведение.
