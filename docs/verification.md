# Проверка FigmaSpark

Проверено 1 октября 2026 года: Node.js 22 и Figma Desktop на macOS. Приведены условия и результаты локальных проверок. Пользовательские макеты, URLs, названия страниц, сборки с локальным pairing code и выгрузки в репозиторий не включены.

## Автоматические проверки

`npm run check` прошёл: TypeScript, сборка и **35 тестов**. Проверены:

- Авторизация HTTP и WebSocket, Host и origin, запрет произвольных команд.
- Выбор файла при нескольких сессиях, IDs запросов, таймауты, отмена и сопоставление ответа с правильной сессией.
- Сжатие больших ответов.
- Выдача инструкции и файлов скилла без ключей и содержимого Figma, выбор сессии через локальную ссылку и чтение локальной конфигурации.
- Установка скилла, запуск установленного CLI, запрет неявной перезаписи и резервная копия обновляемой установки.
- Обзор разных иерархий, лимиты, пагинация, неполное покрытие, кэш и сброс при изменениях.
- Компактные свойства, сохранение instance overrides и объединение variant definitions.
- Audit и отсутствие ложного совпадения при mixed/unavailable properties и неполном чтении.
- Чтение уже загруженной страницы без обращения к сети и реальная ошибка загрузки незагруженной страницы.
- Отдельное разрешение правок, ожидаемые значения, проверка после ожидания шрифта и откат при ошибке.

Тесты Plugin API используют тестовое окружение. Нативные проверки ниже выполнялись отдельно. Исходный и установленный скиллы валидируются `quick_validate.py` из skill-creator.

## Настоящая Figma

На отдельном тестовом Design-файле подтверждены подключение, обзор, поиск известного текста, компактное чтение двух слоёв и экспорт PNG. Ранее также проверены audit с намеренными расхождениями, хранение отчёта и ограниченная правка тестового текста.

В текущей версии пройден путь **локальная ссылка → актуальная инструкция → скилл → авторизованная сессия → overview → search → snapshot**. Режим чтения сохранён. В этом запуске первое чтение небольшого тестового обзора заняло **39,4 мс**, повтор — **2,7 мс**. Поиск вернул известный текст; snapshot содержит два слоя без усечения.

Клик в настоящем UI подтверждён состоянием accessibility «Инструкции скопированы». Содержимое UI — 120 × 80 px. Внутри нет своих надписей, рамок и панели управления. [Скриншот](media/plugin-screenshot.png) показывает сам плагин с его штатной оболочкой Figma, снятый на тестовом файле. Сон, ожидание, работа насоса при запросах и реакция на ошибку проверялись нативно в ходе разработки.

## Измерения большого макета

Измерения отдельного локального запуска живого Plugin API; запуск CLI, инструмента и время работы модели не включены. Пользовательский файл не опубликован. Время зависит от состояния Figma, сложности слоёв и фонового режима.

| Запрос | Первое чтение | Повтор из кэша | Ответ по HTTP |
| --- | ---: | ---: | ---: |
| Обзор: 35 страниц, 11 блоков | 113,7 мс | 2,3 мс | 3,8 KiB |
| Компактный снимок: 1000 слоёв | 318,1 мс | 63,9 мс | 61,7 KiB |
| Каталог: 12 экземпляров, 10 определений | 8,0 мс | 1,7 мс | 2,4 KiB |
| Поиск имени страницы | 1,3 мс | — | 320 B |
| Поиск по 3456 видимым слоям | 175,6 мс | — | 1,1 KiB |

Десять `ping`: медиана 0,4 мс, p95 0,7 мс. Это время локального запроса, не время ответа агента.

Компактное описание одинаковых первых 1000 слоёв: 844 855 B JSON, полное — 1 628 316 B, разница **48%**. Сжатый компактный ответ — 63 172 B. У обоих чтений были отключены styled text segments и разрешение main components. Это ограниченные выборки, а не полный снимок большого файла. Полное чтение варьировалось от 0,8 до 6,4 с в разных запусках.

Стандартная пагинация возвращала две последовательные порции по 100 уникальных слоёв с `nextOffset` 100 и 200. Каталог объединял общие определения по ключам, сохраняя конкретные свойства экземпляров.

Сравнение с Figma MCP не проводилось. Эти результаты не обещают одинаковую скорость для всех файлов.

## Пределы проверки

Соответствие реального продукта документации не оценивалось: такая документация в этой задаче не предоставлялась. Проверялись канал, обнаружение структуры, поиск, компоненты, объём и скорость чтения. Все удалённые библиотеки целиком и непустые локальные variables в настоящей Figma не проверены. Статический макет не доказывает работу приложения.

GitHub Actions запускает тот же `npm run check` для опубликованных исходников. Нативный Figma-тест не выполняется на CI.
